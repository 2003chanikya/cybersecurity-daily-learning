Topic: Git, GitHub and Version Control



1\. VERSION CONTROL



Version control is a system used to track and manage changes made to files over time.



It helps developers:

\- Track file modifications.

\- Maintain project history.

\- Restore previous versions.

\- Identify changes.

\- Collaborate with other developers.



2\. GIT



Git is a distributed version control system used to track changes in project files and maintain different versions of a project.



Main features:

\- Tracks changes.

\- Maintains commit history.

\- Supports branching and merging.

\- Allows offline version control.

\- Supports team collaboration.



3\. GITHUB



GitHub is an online platform used to host Git repositories.



Main purposes:

\- Store projects online.

\- Share source code.

\- Collaborate with developers.

\- Review code changes.

\- Maintain project history.



4\. DIFFERENCE BETWEEN GIT AND GITHUB



Git:

\- Version control tool.

\- Installed on a local computer.

\- Tracks changes locally.

\- Manages commits and branches.



GitHub:

\- Online hosting platform.

\- Stores remote repositories.

\- Supports collaboration.

\- Provides project sharing.



5\. REPOSITORY



A repository is a location where project files and their version history are maintained.



Local Repository:

A repository stored on a computer.



Remote Repository:

A repository hosted online, such as GitHub.



6\. GIT COMMANDS PRACTICED



git --version



Displays the installed Git version.



git clone



Downloads a remote repository to a local computer.



Example:

git clone https://github.com/username/repository.git



cd



Changes the current directory.



Example:

cd project-folder



pwd



Displays the current working directory.



git status



Displays the current state of the working directory and staging area.



mkdir



Creates a new directory.



Example:

mkdir Daily-Learning



ls



Lists files and directories.



touch



Creates a new empty file.



Example:

touch Day-01.md



notepad



Opens a file in Windows Notepad.



Example:

notepad Day-01.md



git config



Configures Git username and email.



Example:

git config --global user.name "Your Name"



git config --global user.email "your-email@example.com"



git add



Adds file changes to the staging area.



Example:

git add Day-01.md



git commit



Records staged changes in the local repository.



Example:

git commit -m "Added daily learning notes"



git push



Uploads committed changes to the remote repository.



Example:

git push origin main



7\. GIT WORKFLOW



Working Directory:

The location where files are created and modified.



Staging Area:

The area where changes are prepared before committing.



Local Repository:

Stores committed changes and project history.



Remote Repository:

Stores the project online.



Basic workflow:



Working Directory → Staging Area → Local Repository → Remote Repository



Commands:



git add → git commit → git push



8\. IMPORTANT GIT TERMS



Commit:

A recorded snapshot of changes in a repository.



Branch:

An independent line of development.



Main:

The primary branch of a repository.



Origin:

The default remote name commonly assigned when cloning a repository.



Git Identity:

The username and email configured to identify commit authors.

11\. GIT COMMAND SUMMARY



git clone – Downloads a remote repository.



git status – Checks repository status.



git add – Stages changes.



git commit – Records changes locally.



git push – Uploads commits to GitHub.



git pull – Downloads and integrates remote changes.



git fetch – Downloads remote updates without integrating them.



git branch – Lists or manages branches.



git merge – Combines changes from different branches.
