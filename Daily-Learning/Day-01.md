DAY 01 – GIT AND GITHUB



Date: 05 November 2026



1\. Version Control



Version control is a system used to track and manage changes made to files over time.



2\. Git



Git is a distributed version control system used to track changes in project files and maintain different versions of a project.



3\. GitHub



GitHub is an online platform used to store Git repositories, share code and collaborate with developers.



4\. Git vs GitHub



Git is a version control tool installed on a computer.



GitHub is an online platform used to host Git repositories.



5\. Repository



A repository is a location where project files and their version history are stored.



Local Repository: Stored on my computer.



Remote Repository: Hosted online, such as GitHub.



6\. Git Commands Learned



git --version

Displays the installed Git version.



git clone

Downloads a remote repository to the local computer.



git status

Displays the current repository status.



cd

Changes the current directory.



pwd

Displays the current directory path.



mkdir

Creates a new directory.



ls

Lists files and directories.



touch

Creates an empty file.



notepad

Opens a file in Windows Notepad.
